# Fawry Employee App V7

تمت معالجة نقطتين أساسيتين:

1. **حفظ Cards وFawry Yawmy عند الانصراف**
   - التطبيق يرسل القيم إلى جدول `attendance` في Supabase.
   - بعد نجاح الحفظ تظهر رسالة نجاح ويعود الموظف للصفحة الرئيسية.
   - لوحة المدير تقرأ بيانات اليوم من `attendance`، ويوجد زر تحديث يدوي.
   - أضفنا تحديثًا تلقائيًا للوحة المدير كل 15 ثانية أثناء بقائها مفتوحة، لذلك بعد حفظ الموظف ستظهر الأرقام عند دورة التحديث التالية.
   - لا تعتمد على localStorage أو بيانات الجهاز كوسيط بين الموظف والمدير.

2. **تغيير كلمة المرور**
   - الموظف لديه زر `🔐 تغيير كلمة المرور`.
   - المدير لديه زر `🔐 تغيير كلمة مرور المدير`.
   - التغيير يتم مباشرة عبر Supabase Auth باستخدام جلسة المستخدم الحالية.
   - الحد الأدنى 8 أحرف مع تأكيد كلمة المرور.
   - لا يتم وضع Service Role Key داخل التطبيق.

## مهم
لا يمكن للتطبيق إظهار بيانات على جهاز المدير إذا كان Supabase غير موصل ومهيأ. يجب وضع URL و ANON/PUBLISHABLE KEY الصحيحين في `AppConfig.kt` وتشغيل SQL والإعدادات الموجودة في ملفات المشروع.
